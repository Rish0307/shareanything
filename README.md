## 🚀 Getting Started

1. **Install Dependencies**:
   ```bash
   pnpm install
   ```
2. **Typecheck Workspace**:
   ```bash
   pnpm run typecheck
   ```
3. **Build**:
   ```bash
   pnpm run build
   ```
